# صور الإعلانات

ست أفكار، كل واحدة بأربع مقاسات. كلها اسكرينات حقيقية من البرنامج (محل تجريبي).

| الفكرة | العنوان |
|---|---|
| `01-main` | محلك كله في برنامج واحد |
| `02-offline` | النت قطع؟ الكاشير شغال |
| `03-repairs` | استلم جهاز الصيانة في ثواني |
| `04-profit` | مكسبك الحقيقي كل يوم قدامك |
| `05-imei` | كل موبايل متتبع بالـ IMEI |
| `06-offer` | خصم 50% لأول 100 محل (FOUNDERS50، لحد 30 نوفمبر — شيلها بعدها) |

| المقاس | فين يتحط |
|---|---|
| `square-1200x1200` | فيسبوك / إنستجرام Feed، جوجل Display (مربع) |
| `portrait-1080x1350` | فيسبوك / إنستجرام Feed (4:5 — بياخد مساحة أكبر على الموبايل) |
| `story-1080x1920` | Stories و Reels (آخر 300px تحت فاضية عشان زراير إنستجرام) |
| `landscape-1200x628` | جوجل Display، فيسبوك Link ads |

اتعملت بـ `build.py` (القالب والكلام فيه).
